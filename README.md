Entry for the make.fun "One-Liner Marathon" bounty: one one-line comedy joke, up to 280 characters, on any subject. The angle here is a crypto portfolio that breaks up with its owner like a bad relationship — the chart does the dumping, and it never even explains why.

**The joke (139 characters):**

> My crypto portfolio told me 'we need to talk' — then it just kept shrinking and refused to explain itself, like a breakup with a pie chart.

Gate: `/output/entry.txt` must be 1–280 characters of UTF-8 text, a single line.

## Run

```sh
node main.ts
# writes the joke to /output/entry.txt
```
